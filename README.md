# Hasanudin — Procurement Specialist

Portfolio for Procurement Specialist opportunities, adapted from the Vendor Management portfolio.

Static GitHub Pages website: `index.html` and `Profile.jpg`. Styling is bundled into the page.

Features: Indonesian/English content, light/dark mode, responsive navigation, procurement evidence, professional experience, STARLITE and SIAP NIKAH sample-data demos, contact links, and browser print/PDF export.

Historical job titles and operating metrics follow the Vendor Management reference. Reconciliation volume is not represented as savings. Interactive demos are served from the reference portfolio.
